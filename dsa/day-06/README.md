# DSA Day 6 — Stack and Queue Fundamentals

## Goal
Recognize LIFO/FIFO patterns and know when a stack or queue gives a simpler solution.

## Problems
1. Valid parentheses
2. Min Stack
3. Next Greater Element
4. Implement a queue
5. Evaluate postfix expression

## Interview pattern
Ask:
- What must be processed last-in-first-out?
- What must be processed first-in-first-out?
- Can a monotonic stack maintain the invariant?
- What are the operation complexities?

## Key connection
Stacks are common in parsing, DFS and undo-style problems. Queues are common in BFS and ordered work processing.
