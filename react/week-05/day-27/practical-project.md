# Day 27 Practical Project

Use the real company project; do not refactor production code just for practice.

Find one screen with a large list/table, expensive filtering/sorting, callback-heavy children, or noticeable rendering work.

Document the symptom, evidence/profile, actual bottleneck, unstable props, whether React.memo/useMemo/useCallback help, whether virtualization/pagination/server-side work is better, and what you will measure before and after.

A decision to not add memoization is valid. The goal is a defensible engineering decision.
