# DSA Day 1 — Big-O + Arrays

## Goal
Build the foundation for solving coding-round problems in JavaScript.

## Topics
- Big-O time complexity
- Big-O space complexity
- Arrays
- Traversal
- Searching
- Min/max
- Frequency counting
- Brute force vs optimized thinking

## 90-minute plan
- 20 min: Big-O
- 20 min: array patterns
- 35 min: coding problems
- 15 min: explain solutions aloud

## Problems
1. Find maximum number.
2. Find minimum number.
3. Reverse an array.
4. Find whether a target exists.
5. Find the second largest distinct number.
6. Count frequency of values.

## Rule
For every problem:
1. Explain brute force.
2. Code it.
3. State time complexity.
4. State space complexity.
5. Look for a better approach.
