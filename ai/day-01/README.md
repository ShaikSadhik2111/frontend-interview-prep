# AI Day 1 — LLM Fundamentals & API Thinking

## Goal
Understand what an LLM application is before learning RAG, agents, or orchestration.

## 45-minute plan
- 10 min: LLM mental model
- 10 min: tokens/context/model output
- 10 min: API request/response
- 10 min: structured output and prompting
- 5 min: interview revision

## Topics
- LLM vs traditional software
- Prompt, system/developer instructions, user input
- Tokens and context window
- Temperature as a generation-control concept
- Structured output
- Hallucination
- API latency/cost
- Streaming
- Why validation is required

## Real-project task
Look at your planned AI Excel Processing Platform. Identify:
1. What data enters the LLM?
2. What should never be sent?
3. What exact structured result should the model return?
4. How will the backend validate the result?
5. What should happen when the model fails?
