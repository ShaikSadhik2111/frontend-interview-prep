# AI Day 6 Common Mistakes

1. Letting the model directly access privileged systems.
2. Trusting tool arguments without validation.
3. Putting authorization rules only in prompts.
4. Giving agents unrestricted tools.
5. Missing maximum-step or timeout limits.
6. Using agents for deterministic workflows.
7. Treating retrieved content as trusted instructions.
8. Executing non-idempotent actions without a confirmation/idempotency strategy.
