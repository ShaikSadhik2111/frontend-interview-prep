# Day 26 Practical Project

Choose one real feature from your company project.

Look for:
- several related state fields
- loading/success/error states
- reset/submit/retry behavior
- multiple transition paths

Document:
1. Current state shape.
2. Components that read/update it.
3. Current transition problems.
4. Proposed reducer state.
5. Action types.
6. Transition table.
7. Side effects that stay outside the reducer.

Do not refactor production code merely for practice. First prove that the reducer makes the feature easier to reason about.
